Ancient Gem Balloon for Etc. Jam 2025

Perhaps you'll find some treasures deep within this cave :)

This balloon makes use of the Crystal font by Jerry Fitzpatrick.

This balloon is set up to be easily combined with Galla's Forged Metal Balloon: https://github.com/GallaTheGalla/forged_metal_balloon/releases/latest
It contains some redundant settings to make this as easy as possible. If you intend to do other customizations, then you may need to remove those settings. There are notes in descript.txt and each of the balloon settings files.

Note: when combining this balloon with Forged Metal (or another balloon), please be sure to change the installation directory in install.txt, otherwise it may overwrite the user's copy of the unmodified balloon. The name of the balloon should also be changed to avoid confusion.
Further notes on combining and balloon permissions can be found here: https://ukagaka.zichqec.com/permissions#balloons
